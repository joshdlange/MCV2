==================================================
BACKGROUND
==================================================

Current Marvel Card Vault Market Price behavior is based on ACTIVE eBay listings.

The current pricing service:
- searches active listings
- uses asking prices
- applies an approximately 0.85 multiplier
- stores/results through fields with names such as soldPrice / salesCount

This is not genuine sold-history data.

We attempted to obtain eBay Marketplace Insights access.

eBay Developer Support confirmed:

- Marketplace Insights is restricted
- it is not currently open to new users
- there is currently no alternative eBay API available to us for historical sold-item data

Therefore we are testing Soldgraph as the sold-data provider.

==================================================
BEST OFFER HANDLING
==================================================

This is important.

Soldgraph exposes:
best_offer_accepted

When best_offer_accepted=true:

the displayed price may be the original asking price, NOT the actual accepted sale amount.

Therefore:

DO NOT include those rows in the primary sold-price median unless we explicitly decide otherwise later.

For initial integration:

PRIMARY PRICE CALCULATION:
use sold listings where:
best_offer_accepted != true

Use Soldgraph's:
median_excluding_best_offer

only if it reflects the same filtered listing set we accept.

If our own post-filtering removes listings, calculate our own median from accepted, non-Best-Offer rows.

Still retain/count Best Offer rows separately for diagnostics.

Do not represent Best Offer displayed asking prices as confirmed sold prices.

==================================================

==================================================

For this development integration:

Use accepted, relevant SOLD listings.
