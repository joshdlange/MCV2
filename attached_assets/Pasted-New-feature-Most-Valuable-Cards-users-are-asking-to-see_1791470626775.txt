New feature: "Most Valuable Cards" (users are asking to see their collection by value). Build in
dev, then tell me when it's ready to publish.

PAGE: /collection/value, titled "Most Valuable Cards"
- Shows the signed-in user's collected cards sorted by current market value, 25 at a time, with
  a "Show more" button (next 25). Do the sorting and limiting in the database query, not in the
  browser; it must stay fast for collections of thousands of cards.
- Sort toggle: "High → Low" (default) and "Low → High".
- Filter chip "Hide under $5", ON by default; tap to show all.
- Cards with no price yet: never mixed into the sorted list. Show "X cards don't have a price yet"
  at the bottom.
- Each card: image, name + #, set, year, value in bold, and "×2 · $X total" when they own more
  than one copy. Tapping a card opens the SAME card detail view used elsewhere in the app.
- Top of the page: a summary strip with total collection value, the number of priced cards, and
  "Prices updated [date]".
- Mobile-first (390px), using the existing card grid/list style. Empty state for users with no
  priced cards.
- If the page shows any eBay links or listings, include the EpnDisclosure component (the
  existing test enforces this).
- Build the list as a reusable component so the page, the profile tab and the Market Trends box
  all use the same code.
