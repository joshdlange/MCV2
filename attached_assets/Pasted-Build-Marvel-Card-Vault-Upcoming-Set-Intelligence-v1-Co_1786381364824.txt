Build Marvel Card Vault Upcoming Set Intelligence v1.

Context:
Our current upcoming set workflow is missing some new Topps Marvel releases. We had Topps sets appear publicly through sources like Topps product pages and Blowout Buzz, but they did not hit our RSS feed. We need a more reliable way to stay on top of upcoming Marvel card sets.

Goal:
Create an admin-only Upcoming Set Intelligence tool that monitors multiple sources, detects potential upcoming Marvel card releases, and creates pending candidates for admin review. Do not automatically publish detected sets to users without review.

Must do:
- Keep the current Upcoming Sets feature.
- Add an admin-only detection/review workflow for upcoming set candidates.
- Treat RSS as only one source, not the source of truth.
- Monitor or support manual checks from multiple sources:
  - Topps release calendar
  - Topps product pages
  - Ripped by Topps articles/checklist spotlights
  - Blowout Buzz / First Buzz articles
  - Beckett/checklist pages if already used or easy to support
  - Existing RSS feeds
- Search for Marvel-specific trading card releases, including:
  - Topps Marvel
  - Topps Chrome Marvel
  - Topps Vault Marvel
  - Topps Mint Marvel
  - Topps Marvel Studios
  - Marvel Sapphire
  - Marvel Comics
  - Marvel trading cards
- Create a pending candidate record when a possible upcoming set is found.
- Candidate fields should include:
  - detected set name
  - normalized set name
  - manufacturer/brand
  - year
  - estimated release date
  - source name
  - source URL
  - source type
  - confidence score
  - checklist URL if found
  - image URL if found
  - description/snippet
  - detected at
  - status: pending, approved, ignored, duplicate, needs review
- Add duplicate detection so the same set is not repeatedly suggested.
- Match candidates against existing upcoming sets and existing card sets.
- Add an admin review page or section under Admin → Cards & Sets or Admin → Data & Migrations.
- Admin should be able to:
  - approve candidate into Upcoming Sets
  - edit title/date/description before approval
  - mark duplicate
  - ignore
  - add source notes
  - manually add an upcoming set if automation misses one
- Do not notify users automatically when a candidate is detected.
- User-facing Upcoming Sets should only show approved upcoming sets.
- Add a manual “Run scan now” button for admin.
- Add a dry-run mode that shows what would be detected without writing candidates.
- Add clear logs for source checks and failures.
- Handle failed source checks gracefully.

Source behavior:
- Topps release calendar should be treated as high-confidence if a Marvel set appears there.
- Topps product pages should be high-confidence if the page clearly names a Marvel card product.
- Ripped by Topps should be medium/high confidence depending on content.
- Blowout Buzz / First Buzz should be medium confidence and require review.
- Checklist sites should be medium confidence unless release date and product name are clearly present.
- Reddit or social/community sources should not auto-create approved sets. If used later, they should only create low-confidence review candidates.

- Do not send emails or push notifications.
