Upgrade Marvel Card Vault Feed v1 UI from a plain activity list into a visually rich collector feed.

Context:
The Feed is now built with Activity, Leaderboards, Trade Feed, reactions, XP, and retroactive/backfilled activity. However, the current Activity feed looks too much like a plain table/list. It needs to feel more like a polished social collector feed.

Current issue:
- Feed cards are plain white rectangles with text only.
- Many events repeat as text-only badge events.
- The word “Feed” appears white on a white/light background, making it hard to read.
- Activity items should be more visually appealing and should show relevant imagery where available:
  - badge image/icon for badge events
  - card image for card-related events
  - set/subset image or representative card image for set completion events
  - PC Binder cover/preview image for binder events
  - avatar and collector identity
- The feed should feel like a collector/social product, not an admin table.

Goal:
Redesign the Feed UI to be visually richer, more card-like, mobile-friendly, and aligned with the MCV dark comic/premium style.

Must do:
- Fix the Feed page title contrast issue immediately.
  - The word “Feed” must be readable on the current background.
  - Do not use white text on a white/light background.
- Redesign feed event cards to feel like social cards, not table rows.
- Use a stronger visual layout for each feed item:
  - user avatar
  - display name
  - collector level
  - timestamp
  - event type badge/icon
  - visual preview/image when available
  - event title/body
  - reaction row
  - CTA/link when relevant
- Add visual previews by event type where possible.

Visual preview rules:
- Badge earned event:
  - show the badge icon/image prominently if available.
  - if no badge image exists, show a styled badge emblem/card instead of only text.
- Card milestone event:
  - show a small card stack/card preview visual.
  - if related card image exists, show the card image.
- First card added:
  - show the card image if available.
  - otherwise show a styled card placeholder.
- PC Binder created:
  - show binder cover/preview image if available.
  - otherwise show a styled binder preview card with the binder name.
- Set/subset completed:
  - show representative set/subset image if available.
  - if unavailable, show a styled completion card with set/subset name and progress/completed treatment.
- Image approved:
  - show the approved card image if available.
- Comeback badge:
  - show comeback badge/icon treatment if available.
- Shared binder:
  - show binder preview and clear CTA to view binder if public/shared.

Design direction:
- Use MCV dark premium collector styling.
- Feed cards should have more personality:
  - dark or charcoal card backgrounds, or white cards with strong red/black visual headers
  - subtle red glow or border accents
  - comic-inspired badge/event chips
  - halftone or diagonal energy accents where lightweight
  - clear hierarchy and spacing
- Keep the design readable and not too busy.
- Feed should feel like:
  “Collectors are building, leveling up, completing sets, and showing off their vaults.”
- Keep the app mobile-first.

Suggested feed card structure:
- Top row:
  - avatar
  - display name
  - level pill

- Main content:
  - visual preview on left/top depending screen size
  - event title
  - event detail text
  - related entity name
- Footer:
