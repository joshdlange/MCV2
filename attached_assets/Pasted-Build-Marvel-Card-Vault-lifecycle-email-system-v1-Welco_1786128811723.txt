24-hour first-card nudge:

  - user signed up at least 24 hours ago
  - user has zero cards in their collection
  - user has not already received this first-card nudge
  - user has not unsubscribed or opted out of marketing/lifecycle emails, if preferences exist

- Do not send the 24-hour nudge to all existing users.

Lifecycle frequency cap:
- Add or reuse a lifecycle email tracking mechanism.
- Track:
  - user_id
  - email_type
  - lifecycle_stage
  - sent_at
  - status
  - provider_message_id if available
  - error if failed
- Enforce no more than 1 lifecycle/marketing email per user every 14 days.
- Transactional emails are exempt from this cap.
- Password reset must be exempt.
- Billing/subscription/payment emails must be exempt.
- Image approval/rejection emails can be treated as transactional/product notifications and should not be blocked unless existing preferences say otherwise.
- Badge/XP/product nudges should follow the lifecycle frequency cap unless explicitly marked transactional.
- Make this cap reusable for future lifecycle emails.

Journey-based nurture foundation:

Add draft/template support for these future journey-based lifecycle emails:

1. Empty Vault Nudge
Audience:
- signed up
- zero cards
- did not respond to first-card nudge
- inactive for at least 7 days
CTA:
Add Your First Card

2. Collection Momentum Nudge
Audience:
- has 1 to 9 cards
- has not added a card in 7+ days
CTA:
Add More Cards

3. PC Binder Prompt
Audience:
- Super Hero user
- has cards in collection
- has not created a PC Binder
CTA:
Create a PC Binder

4. PC Binder Upgrade Nudge
Audience:
- Free or Side Kick user
- clicked PC Binders or viewed a Super Hero-only PC Binder prompt
CTA:
Upgrade to Super Hero

5. Missing Image Contribution Nudge
Audience:
- owns cards that are missing images
- has not uploaded an image recently
CTA:
Help Complete the Vault

6. Share Binder Nudge
Audience:
- has completed or meaningfully built a binder/subset/PC Binder
- has not shared it
CTA:
Share Your Binder

7. Wishlist / Chase List Nudge
Audience:
- has cards in collection
- has not added wishlist/chase cards
CTA:
Build Your Chase List

8. Reactivation Email
Audience:
- inactive 30+ days
- has prior collection activity
CTA:
Return to Your Vault

9. New Set Specific Announcement
Audience:
- users who collect or have viewed related set/year/brand/category
- should be specific to actual new set data, not generic
CTA:
View New Set

10. Image Approved XP Email
Audience:
- user submitted image
- image was approved
CTA:
View Your Contribution
