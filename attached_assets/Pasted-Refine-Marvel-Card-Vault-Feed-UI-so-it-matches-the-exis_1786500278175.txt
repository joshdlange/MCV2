Refine Marvel Card Vault Feed UI so it matches the existing MCV design system better.

Context:
The Feed redesign improved the functionality and made activity cards more visual, but the current design still feels slightly disconnected from the rest of Marvel Card Vault.

Current concerns:
- The Feed header gradient does not feel on-brand.
- The red/gold/purple accents compete with each other.
- The gold Follow button is visible, but it feels a little disconnected from MCV’s normal visual language.
- The feed cards are visually better, but they are all large and similar.
- Badge events still dominate the feed visually.
- The feed should feel more like Marvel Card Vault: dark, clean, premium, red/black/white, collector-focused, and comic-inspired without feeling overdesigned.

Goal:
Keep the improved Feed functionality, but refine the design so it feels native to MCV and less like a separate social app.

Must do:
- Preserve all existing Feed functionality.
- Preserve:
  - Activity tab
  - Leaderboards tab
  - Trade Feed tab
  - Everyone / Following / Friends / Me filters
  - Follow/Friends system
  - reactions
  - reaction XP caps
  - leaderboard logic
  - privacy rules
  - grouped/reordered repetitive events
- Redesign the Feed visual style to better match the rest of MCV.
- Remove or soften the current top Feed gradient treatment.
- Use a cleaner MCV-style header:
  - dark charcoal/black
  - subtle halftone or dot texture
  - thin red accent
  - no heavy pink/purple gradient wash
  - readable white text
- Keep the Feed header visually strong but less generic-SaaS.

Feed card hierarchy:
Introduce visual hierarchy so not every event looks equally huge.

Use 3 presentation levels:

1. Hero Moment Card
Use only for major achievements:
- Top 10 Collector badge
- major level milestones
- set/subset completion
- 250/500 card collection milestones
- rare/legendary badges

Style:
- largest visual treatment
- strong image/achievement preview
- red/black base with gold used only for achievement emphasis

2. Standard Visual Card
Use for normal meaningful events:
- PC Binder created
- image approved
- first card added
- normal badge earned
- smaller collection milestones

Style:
- medium visual preview
- image still important, but card is not oversized
- clean layout, less dramatic than Hero Moment

3. Compact Activity Card
Use for grouped/repetitive events:
- multiple badges earned close together
- lower-priority feed events
- repeated same-user/same-type activity

Style:
- compact row/card
- smaller visual strip or icon cluster
- still attractive, but not a giant hero panel

Design rules:
- Main brand palette should be:
  - black / charcoal
  - MCV red
  - white / light gray
- Use gold only for true achievement/status moments:
  - Top 10
  - leaderboard rank
  - major milestones
  - rare badges
- Use purple sparingly:
  - badge chips only if needed
  - do not make purple feel like a second primary brand color
- Avoid too many competing accent colors in one card.
- Event type chips should be subtle and consistent.
- Feed should feel premium, clean, and collector-focused.

Follow button styling:
Current gold Follow button is visible but does not fully match the brand.
