Skill content requirements:
The “MCV Lifecycle Marketing” skill should include:

Purpose:
Help Marvel Card Vault create smarter lifecycle messaging based on user behavior, not generic monthly blasts.

Voice and tone:
- Collector-first
- Fun, clear, and useful
- Comic-inspired but not cheesy
- Short, punchy CTAs
- No em dashes
- No false affiliation language
- Do not claim affiliation with Marvel, Disney, Upper Deck, Topps, or card manufacturers

Marketing principles:
- Send because something happened or did not happen.
- Every email should have a specific reason.
- Every email should have one primary CTA.
- Avoid generic “monthly update” emails unless they are truly personalized and content-rich.
- Prefer behavior-based triggers over calendar-based blasts.
- Respect unsubscribe/preferences.
- Avoid over-emailing users.
- Batch large sends to respect Resend limits.
- Test to admin before any production campaign.

Lifecycle stages to support:
1. Activation
   - signup completed but no cards added
   - first card added
   - collection started but stalled
2. Engagement
   - user adds cards
   - user creates PC Binder
   - user adds wishlist/chase cards
   - user shares binder/PC/profile
3. Contribution
   - user views missing image
   - user owns cards missing images
   - image uploaded
   - image approved/rejected
   - XP earned for approved image
4. Upgrade
   - user nears Side Kick 500-card limit
   - user clicks Super Hero-only feature
   - user creates/wants PC Binder
   - user wants Market Trends or Scan to Add
5. Retention
   - inactive 7 days
   - inactive 14 days
   - inactive 30 days
   - new sets/images added since last visit
6. Referral/sharing
   - binder shared
   - public link viewed
   - signup from shared link
   - XP/badge earned for sharing
7. Community
   - leaderboard placement
   - badge unlocked
   - set completed
   - contribution milestone

Example lifecycle triggers:
- Welcome email after signup
- First-card nudge if no card added within 24 hours
- Add-more-cards nudge after first card
- Create-PC-Binder prompt for Super Hero users
- PC Binder upsell for Free/Side Kick users
- Missing-image contribution prompt
- Image-approved XP email
- Binder-share prompt
- Referral/signup credit email
- Inactive-user reactivation email
- New-set-specific announcement
- New-image-coverage update

Rules for future email builds:
- Always include Must do / Must not do / Preserve / QA.
- Never send a campaign without admin test approval.
- Never send to all users without explicit approval.
- Segment users when possible.
- Include unsubscribe/footer for marketing emails.
- Use production app links only after confirmation.
- Log sends and failures.
- Rate limit or batch sends to stay within Resend plan limits.
- Do not expose API keys.
- Do not hardcode secrets.
