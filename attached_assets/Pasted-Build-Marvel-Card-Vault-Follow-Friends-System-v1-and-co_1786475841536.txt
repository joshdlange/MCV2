Build Marvel Card Vault Follow / Friends System v1 and connect it to Feed.

Context:
Feed v1 has been built with activity, leaderboards, reactions, XP, and Trade Feed coming soon. Collector Profile Customization and avatars are also built.

However, the Feed is missing the core social mechanic: users need to be able to follow each other and eventually become friends/mutuals. This was the main reason for building Feed.

Goal:
Add a safe, privacy-aware Follow/Friends system and connect it to the Feed so users can discover, follow, and filter activity by people they care about.

Core concept:
- Follow is one-way.
- Friends are mutual follows.
- If User A follows User B, User A sees User B in the Following feed.
- If User B also follows User A, they become Friends/mutuals.
- No friend request approval flow in v1.
- No messaging in this task.
- No comments in this task.

Follow rules:
- User can follow another user only if:
  - target user has public profile enabled OR allow followers enabled, depending existing profile privacy design
  - target user is not blocked by the viewer, if block system exists
  - viewer is not blocked by target, if block system exists
  - viewer is authenticated
- User cannot follow themselves.
- Follow button should show:
  - Follow
  - Following
  - Friend / Mutual, if both users follow each other
- Unfollow should work.
- If a mutual friend unfollows, friendship status should disappear automatically.

- Respect:
  - public profile toggle
  - allow followers toggle
  - show activity in feed toggle

- Feed-hidden users should not show public activity.

  - Following
  - Friends
  - Me
- Everyone:
  - shows public/feed-visible activity from users who allow it
- Following:

- Friends:
  - shows activity from mutual follows only
