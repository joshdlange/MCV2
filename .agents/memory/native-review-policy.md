Use the native Apple/Google review popup as the default automatic review experience.

**Why:** The user explicitly requested returning to the native review popup for the next updates to both mobile stores.

**How to apply:** Keep review requests independent of badge rewards, allow store suppression, and avoid repeat prompting. Manual review actions must remain usable even if the OS suppresses an automatic sheet. Trading is subsequent collaborative work, not authorization to build it during mobile release preparation.
