# Marketplace scrapped (decided Aug 11, 2026)

The in-app marketplace (buy/sell between collectors: marketplace pages, seller info, purchase/sale Activity orders, marketplace routes) is **scrapped**. Do not extend, polish, or invest work in this code. It may return someday, so don't delete it either unless asked.

**Why:** Joshua's positioning is that Marvel Card Vault is an add-on/companion to eBay and Whatnot, not a competitor — collectors sell on those platforms, MCV tracks and values the collection.

**How to apply:** When rolling out cross-cutting changes (avatars, user payload fields, etc.), skip marketplace surfaces. When proposing features or tasks, don't suggest marketplace/selling features; trade-related ideas should stay non-monetary (e.g. trade block).
