name: Catalog label readability
description: User preference for restrained card and subset tile typography changes.

Show subset names without cutting them off, using smaller readable text where needed. Keep cards aligned and standardized; card-name truncation is acceptable, but identification should remain easy. Avoid a broad redesign.

**Why:** The user found truncated names hard to identify while adding images and explicitly asked for modest changes, not a redesign.

**How to apply:** Preserve the compact catalog layout, allow subset labels to wrap, and keep identifying card numbers visible.
